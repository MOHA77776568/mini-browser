# مِدار — Mini Browser

متصفح سطح مكتب بواجهة عربية ومحرك Chromium داخل Electron. الإصدار 1.1.1 يضيف مُثبّت Windows لحساب المستخدم فقط، إلى جانب النسخة المحمولة وأدوات التصفح اليومية. عنوان نافذة نظام التشغيل ثابت باسم **مِدار**؛ عناوين المواقع تظهر داخل التبويبات.

## التنزيل والتشغيل

على Windows ‏64 بت، نزّل [Mini-Browser-Setup-User-Windows-x64.exe](https://github.com/MOHA77776568/mini-browser/releases/download/v1.1.1/Mini-Browser-Setup-User-Windows-x64.exe). أغلق مِدار القديم، ثم افتح المُثبّت. يثبّت البرنامج داخل مجلد برامج حسابك، دون طلب صلاحيات Administrator أو عرض خيار التثبيت لكل المستخدمين. بعد اكتماله افتح اختصار Mini Browser من قائمة ابدأ. يمكن إزالة البرنامج من إعدادات التطبيقات في حسابك.

وتتوفر [النسخة المحمولة دون تثبيت](https://github.com/MOHA77776568/mini-browser/releases/download/v1.1.1/Mini-Browser-Windows-x64.exe). للتحديث المحمول، أغلق النسخة القديمة واستبدل ملف EXE. تُحفظ بيانات المستخدم في مجلد التطبيق الخاص بحساب Windows، ولذلك تبقى عند استبدال الملف التنفيذي أو الانتقال إلى النسخة المثبّتة. نقل ملف EXE إلى جهاز آخر لا ينقل ملفات تعريف الارتباط أو السجل تلقائيًا. تتوفر بصمتا الملفين في [SHA256SUMS.txt](https://github.com/MOHA77776568/mini-browser/releases/download/v1.1.1/SHA256SUMS.txt).

حمّل الملف كاملًا من المتصفح قبل فتحه. اختصار Internet Shortcut الذي يحمل عنوانًا مؤقتًا مثل `blob:` لا يحتوي البرنامج. عدم طلب صلاحيات Administrator لا يتجاوز سياسات الجهاز أو الحظر الذي يفرضه برنامج آخر مثل Cold Turkey. قد يعرض Windows تحذير سمعة للملفات غير الموقعة، وهو منفصل عن طلب صلاحيات Administrator.

## أدوات التصفح

- تبويبات عادية وخاصة، مع استعادة الجلسة وإعادة فتح التبويب المغلق وتثبيت التبويبات وكتم الصوت.
- سجل قابل للبحث والحذف، ومفضلة قابلة للإدارة.
- مدير تنزيلات يعرض التقدم، مع الإيقاف المؤقت والمتابعة والإلغاء وفتح الملف أو إظهاره في المجلد.
- بحث داخل الصفحة، وتكبير محتوى الموقع، وطباعة وحفظ PDF أو صفحة ويب.
- قوائم سياقية للروابط والصور والنصوص وأدوات التحرير.
- إعدادات لمحرك البحث Google أو DuckDuckGo أو Bing، والصفحة الرئيسية، واستعادة الجلسة والمظهر.
- إدارة أذونات المواقع ومسح السجل أو ملفات تعريف الارتباط أو الذاكرة المؤقتة حسب اختيار المستخدم.

التبويبات الخاصة تستخدم جلسة مؤقتة منفصلة؛ لا تضاف إلى السجل أو الجلسة المستعادة. الملفات التي تختار تنزيلها تبقى على القرص. التصفح الخاص لا يخفي اتصالك عن المواقع أو مزود الإنترنت.

تدعم صفحات الويب JavaScript وHTML5 وملفات تعريف الارتباط ورفع الملفات ضمن قدرات Chromium. بعض خدمات DRM أو تسجيل الدخول قد ترفض المتصفحات المضمّنة، وإضافات Chrome ومزامنة حساب Chrome وحفظ كلمات المرور التلقائي ليست ضمن هذا الإصدار. الملفات غير موقعة رقميًا.

## الاختصارات

| الاختصار | الوظيفة |
| --- | --- |
| Ctrl+L | شريط العنوان |
| Ctrl+T / Ctrl+W | فتح تبويب / إغلاق التبويب |
| Ctrl+Shift+T | إعادة فتح التبويب المغلق |
| Ctrl+Tab / Ctrl+Shift+Tab | الانتقال بين التبويبات |
| Ctrl+F | البحث داخل الصفحة |
| Ctrl+D | إضافة الصفحة إلى المفضلة |
| Ctrl+R | إعادة التحميل |
| Ctrl+P | طباعة الصفحة |
| Ctrl++ / Ctrl+- / Ctrl+0 | تكبير محتوى الموقع أو تصغيره أو إعادته للحجم الأصلي |

## التطوير والتحقق

استخدم Node.js ‏24 أو أحدث إصدار مدعوم ابتداءً من 22.12، ثم من مجلد المشروع:

```sh
npm ci
npm exec -- install-electron --no
npm start
```

التطبيق نافذة سطح مكتب فعلية، ولا يعمل كمعاينة ويب على localhost. لا يحتاج إلى مفاتيح API أو خدمات خارجية خاصة بالتطبيق.

```sh
npm test
npm run test:e2e
```

الاختبارات الوظيفية تشغّل Electron وتحتاج إلى جلسة رسومية. في البيئة السحابية الحالية، استخدم `npm run test:cloud` لإنشاء شاشة Xorg مؤقتة وإغلاقها بعد الاختبارات. تعطيل عزل نظام التشغيل الخاص بـ Chromium محصور بهذا الاختبار المؤقت بسبب قيود الحاوية؛ التشغيل العادي ونسخة Windows يحتفظان بالعزل.

يمكن تغيير مجلد بيانات التطوير أو الاختبار عبر `MINI_BROWSER_USER_DATA`. البيانات القديمة في `bookmarks.json` تُستورد إلى مخزن الملف الشخصي الجديد مع الاحتفاظ بالملف الأصلي.

## بناء نسخ Windows

على Windows:

```sh
npm run dist:win
```

يبني هذا الأمر المُثبّت لحساب المستخدم ثم النسخة المحمولة. لبناء أحدهما فقط:

```sh
npm run dist:win:installer
npm run dist:win:portable
```

ومن Linux عند تجهيز أدوات البناء، يمكن بناء النسخة المحمولة وحدها:

```sh
npm exec -- electron-builder --win portable --x64 -c.win.signAndEditExecutable=false --publish never
```

سير العمل `Build Windows release` يختبر المصدر الموسوم على Windows، ثم يبني مُثبّت NSIS والنسخة المحمولة. يختبر المُثبّت وإزالته بحساب Windows عادي، ويتحقق من أن مستوى التنفيذ `asInvoker` ومن التسجيل داخل HKCU دون تثبيت على مستوى الجهاز. يرفع الملفين وبصمتيهما إلى مسودة الإصدار الموجودة، وتُنشر بعد التحقق. يُبنى NSIS أولًا حتى يُنشأ أرشيف التطبيق المشترك دون مساعد رفع الصلاحيات.

## اتصال السحابة

الاتصال العام يعتمد على إعداد شبكة البيئة. إذا ظهر `ERR_CERT_AUTHORITY_INVALID` خلف وكيل المنصة، تحقّق من شهادة CA التي توفرها المنصة ومن صلاحية كتابة Chromium إلى مخزن NSS في `~/.pki/nssdb` قبل استيراد أي شهادة. أبقِ التحقق من TLS مفعّلًا، ولا تستخدم تجاوز أخطاء الشهادات لحل المشكلة.
